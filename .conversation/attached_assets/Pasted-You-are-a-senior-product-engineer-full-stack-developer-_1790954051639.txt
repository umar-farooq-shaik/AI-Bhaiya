You are a senior product engineer, full-stack developer, AI engineer, UX architect, and product designer.

Build **AI Bhaiya**, a polished, functional, personalized AI learning platform for **anyone who wants to learn AI** — including non-technical beginners, students, developers, career switchers, and working professionals.

The core product idea is:

> **AI Bhaiya — A personalized AI tutor that identifies what you know, finds your gaps, and adapts lessons and practice to help you master AI skills.**

Do NOT build this as a generic chatbot or generic online-course website. The central differentiator must be **personalized, adaptive learning**.

---

# 1. TECH STACK

Use:

* React.js
* JavaScript or TypeScript
* Node.js + Express.js where a backend is needed
* Modern component architecture
* Responsive design
* REST APIs where appropriate
* Environment variables for all API keys/secrets
* Clean, maintainable folder structure

For AI functionality:

* Use the **Gemini API**
* Model: `gemini-3.6-flash`
* If this model is not working use another gemini ai model.
* Never expose the Gemini API key in frontend code
* Store it securely as an environment variable
* Create a reusable backend AI service instead of scattering Gemini calls throughout the application

Use free/open-source tools and services wherever possible.

Suggested free options where appropriate:

* Gemini API for AI
* Supabase free tier for database/authentication if needed
* GitHub API for developer/AI ecosystem signals
* Hacker News API for technology/trend signals
* Public/free job APIs for job listings where available
* Local JSON/seed data as a fallback for demo content
* Replit deployment/tools where available on the current plan

Do not add paid services unless absolutely necessary.

# 3. CORE USER PROBLEM

The platform should explicitly solve this problem:

Most AI learning platforms give everyone the same lessons regardless of what they already know, how quickly they learn, or where they struggle.

AI Bhaiya should instead determine:

* What the learner already knows
* What they don't know
* What they want to achieve
* How much time they have
* Their preferred learning pace
* Their current skill level

Then dynamically create and adjust their learning journey.

# 6. ADAPTIVE LESSON ENGINE

This is the most important part of the product.

Lessons should not simply be static articles.

Each lesson should contain:

### Learn

Clear explanation adapted to the learner's level.

### Example

Real-world examples.

### Try it

Interactive activity.

### Practice

AI-generated exercises based on the learner's current knowledge.

### Check understanding

Short questions or mini challenge.

### Adapt

Based on performance:

* If the learner performs well → increase difficulty
* If they struggle → simplify the explanation
* If they repeatedly make the same mistake → provide targeted remediation
* If they finish quickly → offer an advanced challenge

Use Gemini to generate personalized explanations and exercises.
